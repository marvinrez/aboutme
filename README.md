# aboutme

**How I build**

My workflow blends design and engineering:

1. Prototype in code early to test behavior, not just screens

2. Use LLMs as co-creators for layout, variations, and microinteractions

3. Structure prompts as systems with constraints and expected outputs

4. Validate with real usage, logs, and edge-case scenarios

5. Keep interfaces minimal and behavior predictable
